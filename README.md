# Emprendedores Puerto Montt - PuertoEmprende

Proyecto semestral de Programación en Android (2026). Plataforma que busca ser el punto de encuentro del emprendimiento en la comuna de Puerto Montt, tanto para vender como para comprar.

* **Emprendedoras:** Gestionan su tienda, catálogo, inventario y participación en ferias.
* **Compradores:** Conocen y siguen a las emprendedoras, y reciben avisos de ferias.
* **Administrador:** Registra emprendedoras, asociaciones y gestiona ferias.
